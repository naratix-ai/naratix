# Errors

Every error names its fix, such as the tool that lists a missing id: fix the call and retry once before involving the user. A launch refused as already running is running (Start and a yes in the chat): follow it; when a card's context says a press got no answer, it may have gone through: read it again as that line says and redo only what is not there. A permission refusal goes to the user with what they can do instead. The launch limit (too many actions in a minute) clears by itself: wait a minute, then retry once.
